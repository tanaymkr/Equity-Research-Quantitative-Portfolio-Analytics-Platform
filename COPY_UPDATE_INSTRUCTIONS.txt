Investment Research Platform: SQL/data copy-and-paste update

1. Extract Investment_Platform_SQL_Update.zip.
2. Open the extracted folder. Copy ALL its contents into your existing
   repository folder: the folder containing run_tega_model.py and src.
3. Merge the folders and choose Replace files in the destination when asked.
   Do not put the extracted parent folder inside the repository.
4. Double-click Run_Data_Pipeline.bat, or run:

       python run_data_pipeline.py

5. Open outputs/data/tega/analysis.html.

This update is for the repository baseline
187cd0683ae1c179cfd93484b5c5a326d175447a (Investment Platform Update).
If you have made your own edits to these files, keep a backup before replacing.

The update builds a SQLite financial-data store and dated financial analysis.
Running it again is supported: existing facts are not duplicated. The database
is created at outputs/data/research.sqlite. Python includes SQLite already.

No manual file deletion or patch command is required. Existing source examples
remain in your repository. Read START_DATA_PIPELINE.md for details and commands.

The new database includes TEGA reported data and a labeled synthetic DEMO.
Prices, additional real companies, factors, portfolios, risk, index analytics
and Streamlit remain future work. The Tega valuation launcher still works.

After reviewing the files in GitHub Desktop, you can commit and push them
using your usual workflow. Copying files and running the model do not publish.
