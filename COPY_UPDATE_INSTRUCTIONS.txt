Investment Research Platform: copy-and-paste foundation update

1. Extract Investment_Platform_Copy_Update.zip.
2. Open the extracted folder. Copy ALL its contents into your existing
   repository folder: the folder containing run_tega_model.py and src.
3. Merge the folders and choose Replace files in the destination when asked.
   Do not put the extracted parent folder inside the repository.
4. Double-click Run_Tega_Model.bat, or run:

       python run_tega_model.py

5. Open outputs/tega_molycop/report.html.

This update is for the repository baseline
cf9e1c4c7fe4e1b9c5f27d10c65c7dfd16089206 and its previous Tega model files.
If you have made your own edits to these files, keep a backup before replacing.

The update relocates Tega code and improves project documentation. It does not
change the supplied valuation inputs. Current scenario results should remain
approximately INR294.22 downside, INR1,171.99 base and INR1,734.08 upside.

It contains compatibility files for old code locations, so no manual file
deletion is required. Existing examples and assumptions are not included in
this update and remain in your repository. No patch command is required.

SQL, factors, portfolios, risk, index analytics and Streamlit are future stages.
Running the Tega launcher generates the existing Tega report only.

After reviewing the files in GitHub Desktop, you can commit and push them
using your usual workflow. Copying files and running the model do not publish.
